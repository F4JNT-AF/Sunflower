# [FR] "Tournesol"
Un disque PCB à mettre entre le pieu de mise à la terre et le point d'alimentation d'une antenne verticale utilisant une vis M10 (type JPC-12 mais devrait être compatible avec la MC-750).
Le "Tournesol" permet de connecter jusqu'a 16 radiants en utilisant des fiches banane standard de 4 mm.

Voir [la publication de Rudy Severns, N6LF](https://www.antennasbyn6lf.com/ARRL_articles/QEX%20May-Jun%202009%20Ground%20systems%20part-4.pdf) dans le QEX de Mai/Juin 2009.
16 radiants semble être un bon milieu entre simplicité de mise en oeuvre et gain d'efficacité.

:warning: Design non-testé pour l'instant.


# [EN] "Sunflower"
A PCB disk that goes between the grounding stake and the feedpoint of a vertical antenna using a M10 screw (such as the JPC-12 but it should be also compatible with MC-750).
This "Sunflower" allows connecting up to 16 radials using standard 4 mm banana plugs.

See [N6LF's (Rudy Severns) publication](https://www.antennasbyn6lf.com/ARRL_articles/QEX%20May-Jun%202009%20Ground%20systems%20part-4.pdf) in May/June 2009 QEX.
16 radials seems to be a good compromise between ease of use and efficiency gain.

:warning: Untested design for now.
